# Cardplug.com

Trade gift cards for instant Naira at the best rates in Nigeria.

## Features

- 40+ supported gift cards (Amazon, Apple, Steam, Google Play, Razer, etc.)
- Live payout calculator in Naira
- Searchable rate table
- Fully responsive dark-themed UI
- Single-file build (HTML + CSS + JS)

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (ES6+)
- No build tools, no dependencies

## Local Development

Just open `index.html` in any modern browser — no server needed.
